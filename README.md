# Monsoon-to-Margin
### Live Quick-Commerce Demand & Disruption Dashboard

Run:
```bash
pip install -r requirements.txt
streamlit run app.py
```

Weather rainfall and temperature come from Open-Meteo. Quick-commerce orders, delivery times, cancellations, rider availability, revenue and disruption costs are simulated with a documented severity model because real order data is not public. The app also contains an offline fallback.
